# Working on this repository

Instructions for coding agents (Codex, Claude Code and others) that edit this repository. They are not part of the skill; the skill starts at `SKILL.md`.

## Layout

| Path | What it is |
|---|---|
| `SKILL.md` | Skill core. Loaded on every run. |
| `references/` | Detail loaded on demand: `en/` (`patterns.md`, `final-pass.md`, `examples.md`), `pt-br/` (`padroes.md`, `revisao-final.md`, `exemplos.md`), and the shared `voice-and-genres.md` and `sources.md`. |
| `agents/humanizer-revisor.md` | Claude Code subagent. |
| `agents/openai.yaml` | Codex metadata for the skill (display name, implicit invocation). |
| `codex/humanizer-revisor.toml` | The same subagent as a Codex custom agent. |
| `.claude-plugin/` | Claude Code plugin and marketplace manifests. |
| `plugins/codex/` | Codex plugin, generated by `scripts/build-codex-plugin.py`. Do not edit by hand. |
| `assets/icon.png` | Plugin icon. |
| `scripts/build-codex-plugin.py` | Builds `plugins/codex/`; `--check` fails when it is out of date. |
| `scripts/check-wikipedia.py` | Reports changes in the Wikipedia pages behind the catalog. |
| `wikipedia/` | Extraction of those pages and the recorded revisions. The skill does not read it. |

## Rules

- English is the primary language. Content about Portuguese stays in Portuguese: `references/pt-br/revisao-final.md`, Portuguese triggers and examples, and the Portuguese Wikipedia extraction.
- Keep `SKILL.md` short (under 200 lines). Move detail to `references/` and say in the core when to open it.
- The `description` in the `SKILL.md` frontmatter stays at or under 200 characters, the claude.ai upload limit.
- Two catalogs with independent numbering: `references/en/patterns.md` (EN01-EN78) follows the English Wikipedia page, `references/pt-br/padroes.md` (PT01-PT86) follows the Portuguese pages. IDs are not shared across languages. Rules R01-R12 and sources S01-S24 keep their IDs.
- A new Wikipedia section or sign becomes a new ID with the next free number in that catalog, placed at the end of its section group. Existing IDs are never renumbered; a retired ID is not reused. An addition from another source or editorial practice goes in the "Additions" part of the catalog and says so in its **Sources** line.
- Each catalog ends with a mapping table from the old P01-P50 IDs; keep it as is.
- Every pattern ends with a `**Sources:**` line (`**Fontes:**` in the Portuguese catalog). A new source enters `references/sources.md` with an ID, and the README appendix gets the same row in both languages.
- Sources are primary only: Wikipedia editorial guides, peer-reviewed or preprint research, research institutes, vendor documentation and style guides. Do not cite other repositories or projects.
- Prose follows the skill itself: no filler, no promotional vocabulary. Wikipedia is the reference for what counts as an AI-writing sign; when a page moves a sign to the historical or ineffective indicators, the rules follow.

## Before a release

1. Run `python scripts/check-wikipedia.py`. If a page changed, read the diff, update `wikipedia/` and the catalog, then run it again with `--record`.
2. Run `python -I scripts/build-codex-plugin.py`, then `python -I scripts/build-codex-plugin.py --check` (must exit 0), then `claude plugin validate .`.
3. Bump the version in `SKILL.md` (`metadata.version`), `.claude-plugin/plugin.json`, `CHANGELOG.md`, `README.md` and `README.pt-BR.md`.
